Rehoboth Solutions Limited website

HOW TO PUT IT ONLINE
1. Buy a domain name from a registrar (for example a .com or .com.ng).
2. Get web hosting. Any static host works, such as Netlify, Cloudflare Pages, GitHub Pages or a normal cPanel host.
3. Upload everything in this folder, keeping the folders (css, images, js) as they are. index.html must be in the top folder.
4. Point your domain to the host by following the host's instructions.

THINGS TO KNOW
- The contact form opens the visitor's email app. For a form that sends messages directly, use a service such as Formspree or Netlify Forms.
- Edit text in any .html file with a text editor. Colours are at the top of css/styles.css.
- Replace the photos in the images folder with the same file names to change them.
